# kisko-doorbell RFCs

This tree follows [RFC 0001](0001-rfc-process.md). Isolation is off, so RFCs may name repository paths a reviewer can open.

## Numbering

0001 defines the process. 0002 through 0099 record contracts that shipped before the process. 0100 through 0999 are available for later proposals.

## Product coverage

The Stable RFCs cover the shipped command-line, RF intake, and Slack delivery behavior. Review contract changes against the executable specs under `spec/` and the implementation under `exe/` and `lib/`.
